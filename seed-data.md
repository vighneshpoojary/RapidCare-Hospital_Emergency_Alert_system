## How to Use

1. Register a hospital using the Hospital Interface
2. After logging in as the hospital, add doctors
3. Set doctor status to "AVAILABLE"
4. Register a patient using the Patient Interface
5. Search for hospitals by city
6. Select a hospital and send an emergency request
7. Switch to Hospital Interface to see the emergency notification
8. Assign a doctor to accept the emergency
9. View real-time status updates on both interfaces
